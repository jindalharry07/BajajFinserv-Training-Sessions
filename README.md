## 🛠️ Getting Started

### Prerequisites
- JDK 11 or higher
- A Java-compatible IDE or terminal

### Execution
To run any solution, navigate to the root directory and use the following commands:

```bash
# Compile the specific module
javac Day-1/MaxSubArray.java

# Execute the class
java -cp Day-1 MaxSubArray
```
